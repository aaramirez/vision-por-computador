# Visión por computador

Cómo una computadora interpreta imágenes: filtros y bordes, características y correspondencias, geometría de cámaras y calibración, estéreo y reconstrucción 3D, flujo óptico, seguimiento, segmentación y detección de objetos, con una app que usa la cámara del lector.

**Ver en línea:** https://aaramirez.github.io/vision-por-computador/

Este repositorio solo tiene el sitio generado. El curso está en preparación: la tabla de contenido ya está publicada para revisión.
